# Independent ITCH golden fixture

`golden.hex` was written as hexadecimal wire bytes, independently of the
synthetic generator and both decoders. Each line is one BinaryFILE record:
two-byte big-endian payload length, followed by the payload; the last `0000`
is the file terminator. Whitespace is for inspection. `golden.bin` is exactly
`bytes.fromhex(golden.hex)`; `golden_expected.json` contains separately
hand-calculated expectations, not output generated by the C++ implementation.

The 553-byte fixture has 18 payload messages and nine target updates. All
timestamps encode `01 02 03 04 05 06` (1,108,152,157,446 ns). TEST uses locate 1;
OTHER uses locate 2. S/O begins the session, S/E is followed by another target
update, and S/C precedes the zero-length terminator.

The hand calculation can be checked in order:

1. F adds bid 10, 100 shares at 10000, attribution ABCD. A adds bid 11 with
   50 at the same price and ask 20 with 80 at 10100.
2. C executes 30 from order 10 with Printable=N and execution price 999999:
   order 10 still displays 10000 with 70 shares; bid level total is 120.
3. E removes 20 from ask 20; X removes 20 from bid 11.
4. U replaces 10 with 12, new total 90 at 10200, preserving bid side and ABCD.
   This crosses the 10100 ask; reconstruction does not invent a match.
5. D removes 11. P/Q/B are counted but do not change visible orders. An OTHER
   deletion with an unknown reference is filtered. After S/E, X removes all
   90 shares of order 12.
6. The final book contains only ask 20: 60 shares at 10100, empty attribution.

From the repository root, after building Release:

```sh
python3 scripts/verify_itch.py --binary build/release/itch_replay \
  --input data/itch/golden.bin --symbol TEST --output-dir build/itch-golden-check
python3 tests/itch_cli_test.py --binary build/release/itch_replay \
  --output-dir build/itch-cli-check
```

The CLI test also compares the independent Python results with the hand-written
expectations, exercises split reads, lifecycle boundaries and malformed inputs,
and executes retained verifier failure commands. Its output directory contains
`latest.json` pointing to the retained run and `test-summary.json` within it.

The fixed synthetic streams are generated by `scripts/create_itch_workloads.py`;
their seeds, proportions and legalisation rules are in
[the M5 plan](../../docs/m5_plan.md#frozen-synthetic-generation). These fixtures
are synthetic, not Nasdaq market data. See
[reproduction commands](../../docs/m5_reproduction.md) for the long check,
finite Linux matrix and separately bounded historical acquisition, and
[supported semantics](../../docs/itch_scope.md) for the message contract.
