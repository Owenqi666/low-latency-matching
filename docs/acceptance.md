依据本地保存的 M1 开发任务书 T00–T09 及项目方针 v2。原始两份计划按用户指定范围保留本地；本清单为公开验收映射，具体契约见 [semantics.md](semantics.md)。

状态：技术实现与复现验收通过；发布状态单独记录在 release。只有取得对应证据后才能勾选；实现存在、配置存在和实际运行通过分别记录。每项证据应包含版本、命令、环境、退出状态及结果路径。本地成功不能替代远端 CI。学习材料展示完整解释路径，不声称读者已经掌握。

- [x] [复现] README 中的工具链要求与命令实际可运行，不把预定接口写成已完成能力。

## T01 — 契约与手算案例（任务书 L319–328）

- [x] [检查] command/event/snapshot 契约明确；市价、限价、撤单分别建模；价格、数量、序号为整数。
- [x] [手算与测试] 第 6 节案例有逐条完整事件和每步状态，包含表中省略的 Accepted/CommandComplete；另外覆盖反向买簿和非法归属。
- [x] [文档与测试] 明确校验优先级、事件顺序、完成数量恒等式、活动 ID 唯一与终态复用、RequestId 不去重、允许自成交、owner 检查和满簿限价拒绝。
- [x] [边界] 非法配置、聚合数量溢出、事件容量加法及分配大小、序号耗尽、输出不足均有确定期望。边界检查集中实施，内部不重复校验已成立条件。

## T02 — 独立参考模型（任务书 L330–339）

- [x] [检查] vector 扫描模型不链接 core，不复用 maker 选择、撮合循环、索引或业务校验逻辑；只共享值类型、配置和序列化契约。
- [x] [测试] 手工 fixture 的完整事件、序号和快照逐项吻合；相同输入重复运行确定；vector 删除移动元素后 FIFO 仍按 arrival_seq。
- [x] [失败注入] 修改手工期望的成交价格或顺序会使测试失败，随后恢复；保存实际失败与恢复结果。

## T03 — 基线订单簿（任务书 L341–352）

- [x] [测试] 多价位、同价 FIFO、头/中/尾删除、最后节点删除和部分成交均覆盖；完全成交同步清理订单索引。
- [x] [不变量] list、hash 一一对应，节点数等于活动订单数，剩余量为正，层内 side/price 一致，价位总量等于剩余量之和，无空价位或悬空 locator。
- [x] [检查] 外部仅获取值快照；持有 iterator 的类禁用复制和移动；删除前取得事件所需数据，不跨 rehash 保留 hash iterator。
- [x] [本地] 本阶段的小规模测试已经在 ASan/UBSan 下运行通过，保留日志；不延后到基准阶段。

## T04 — 限价撮合（任务书 L354–365）

- [x] [测试] 买卖双向覆盖不交叉、恰好交叉、部分成交、多价位 sweep、maker 完全消失和剩余挂簿；成交价始终为 maker 价。
- [x] [测试] 至少三个同价 maker；T05 接入撤单后补测撤掉中间单，其余 FIFO 顺序不变。
- [x] [对拍] 每条限价命令的事件、数量恒等式、快照与参考模型相同；完成后非空双边满足 best_bid < best_ask。
- [x] [边界] 输出小于固定容量要求时，状态、序号和输出哨兵均不改变；验证可扫过 C−1 个 maker 的限价单，不能绕过满簿接纳政策。

## T05 — 市价、撤单及拒绝（任务书 L367–382）

- [x] [测试] 空簿/部分/全部成交的市价单无余量挂簿；满簿 C 个 maker 的市价 sweep 验证事件上界；取消量准确。
- [x] [测试] 部分成交后只撤剩余量；重复、已成交和未知撤单返回 UnknownOrder；非 owner 不改状态；活动重复 ID 在成交前拒绝。
- [x] [测试] 满簿可成交和不可成交 limit 均拒绝，market/cancel 仍可减少活动订单；零值 ID/数量、非法 price/enum、多重错误覆盖固定校验优先级。
- [x] [测试] 业务拒绝不改簿但占 CommandSeq/EventSeq；调用错误不消费序号。终态 ID 复用及重复 RequestId 不暗中引入幂等语义。
- [x] [边界] UBSan 覆盖整数和序号边界；通过内部测试入口或边界检查函数构造耗尽，不新增公共业务接口。不可恢复分配异常不得伪装成普通拒单后继续使用引擎。

## T06 — 随机对拍、重放与缩减（任务书 L384–399）

- [x] [测试] 每命令比较调用级结果、完整事件序列和规范化快照；覆盖撤单密集、拥挤同价、稀疏价位、多价位 sweep、错误 ID/owner 和容量边界。
- [x] [运行记录] 起步 CI 20 seeds × 2,000 commands，覆盖 C=1/2/16/128；另做较长本地验证（任务书示例 100 × 10,000），记录实际种子数、命令数、容量及调整理由，不把样本量当作完备证明。
- [x] [失败产物] 保存配置、生成器版本、种子、实际 trace/hash、首个分歧、双方事件和快照；种子不能替代实际输入证据。
- [x] [失败注入] 注入 FIFO 或成交价错误后，比较器非零退出且缩减器产生更短、同类分歧的输入；每次候选从空引擎完整重放，不修复未知撤单；恢复代码并永久保存回归用例。
- [x] [CLI] 格式错误带行号且非零退出；预期业务 Rejected 且双方一致可成功退出。

## T08 — 核心基准（任务书 L414–452）

- [x] [负载] mixed/cancel_heavy/sweep/clustered 四类、至少两档容量；保存配置、价格带、深度、初态、setup/input hash、种子及真实结果比例。成功/失败撤单分别统计，拒单不能主导正常撮合结论。
- [x] [方法] 计时前解析、分配及参考验证；独立引擎预热，每轮重建同一初态；latency 与 throughput 分开运行。延迟包含结果生成，吞吐逐次消费结果防止消除工作；文件 I/O、快照与参考比较在计时外。
- [x] [正确性] 每轮检查事件/拒绝计数和最终快照；相同输入在计时外核对完整事件。样本不完整、hash 不符或状态不符时脚本失败，不能输出成功报告。
- [x] [结果] Release 无 sanitizer，至少 5 轮原始结果全部保留；报告时钟分辨率与记录开销，不机械减常数。明确分位数算法，按轮及关键类型/结果拆分分布，样本不足时不宣称稳定高分位。
- [x] [环境与口径] commit、依赖、编译器/选项、CPU、OS、虚拟化、内存及可获取 CPU 数据可追溯；不能控制的频率/亲和性如实说明。吞吐同时列完成/接受命令、Trade 和拒绝比例，不报告网络 RTT 或排队指标。
- [x] [独立复现] 由独立执行者在干净 checkout 按公开说明重新生成报告，记录执行者、环境、命令与差异；不要求数值完全相同。任务书要求他人能够复现，不额外要求用户现场演示。

## T09 — 独立交付与学习验收（任务书 L454–467）

- [x] [干净 checkout] 实际完成构建、测试、fixture 重放、差分验证与短 benchmark；记录精确版本及命令。
- [x] [文档] README 第一屏准确描述单线程内存撮合核心与当前状态；两份 ADR 说明 map/list/hash、扫描参考模型、保守容量和全量结果缓冲的选择与代价。
- [x] [证据] 正确性、性能报告及演示绑定同一可识别版本；依赖、输入、原始结果可追溯；正式版本标记及最终 main CI 单独记录在 release，避免与测量源码提交混淆。
- [x] [核心讲解] 提供可手动追踪的 FIFO/部分成交、一次索引删除、失败缩减与一轮 benchmark 解释，并与源码和证据核对。读者可据此自测；交付不宣称读者已完成学习。
- [x] [范围] 明确 M1 缺少的网络/并发/恢复能力，以及 M2 为什么需要可暂停执行和输出背压；未完成内存池或没有优化收益不阻止满足最低要求的 M1 交付。

## 证据缺口的处理

没有远端运行、下载验证、独立 checkout 复现或对应讲解材料时，保留相应未勾选项，并写明缺少什么。可以继续完成互不依赖的实现和本地验证；不能将这些证据缺口记为已经通过。
